# Trial Acceptance Checklist

> 体验版验收清单：小程序上传体验版后，必须逐项验证通过才能提交审核。

## 基础

- [ ] 体验版能打开，不白屏。
- [ ] 能访问 HTTPS 后端（request 合法域名已配置）。
- [ ] uploadFile 合法域名已配置（封面图片上传）。
- [ ] downloadFile 合法域名已配置（图片展示）。
- [ ] 图片能正常展示，无大面积空白或裂图。

## 用户路径

- [ ] 微信登录：点击登录按钮 → 授权 → 进入首页。
- [ ] 选择 Workspace：点击 TabBar「我的」→ 切换 Workspace。
- [ ] 查看书籍列表：首页展示书籍卡片，封面、标题、价格正常。
- [ ] 搜索书籍：搜索框输入关键词，结果正常过滤。
- [ ] 创建书籍：点击「卖书」→ 填写表单 → 上传封面 → 保存成功。
- [ ] 上传封面：选择图片 → 调用 uploadFile → 返回 OSS URL → 展示成功。
- [ ] 编辑书籍：进入详情 → 编辑 → 修改标题/价格 → 保存成功。
- [ ] 分享详情：详情页 → 转发 → 分享卡片正常。
- [ ] 删除书籍：管理员/OWNER 可删除，VIEWER 不可删除。

## 高级能力

- [ ] 创建活动：管理员可创建读书会活动。
- [ ] 创建订单：选择书籍 → 创建订单 → 生成订单记录。
- [ ] Mock 支付：体验版使用 mock 支付，支付成功 → 生成 Ticket。
- [ ] 支付成功生成 Ticket：订单状态变为 PAID，Ticket 状态为 VALID。
- [ ] 订阅活动提醒：详情页 → 订阅按钮 → 调用 requestSubscribeMessage → 成功记录。
- [ ] 客服入口：客服按钮 → 打开客服会话 → 发送消息成功。
- [ ] 内容安全拦截：发布含敏感词的评论/书籍 → 被拦截 → 记录到 ContentSecurityCheck。
- [ ] 管理员复核：管理员进入内容安全复核页 → 可审核通过/拒绝。

## 权限验证

- [ ] VIEWER 不可创建书籍（应返回 403）。
- [ ] MEMBER 不可管理成员（应返回 403）。
- [ ] ADMIN 可处理内容安全（审核通过/拒绝）。
- [ ] 非成员访问 Workspace 资源返回 403。

## 性能

- [ ] 首屏时间 < 2s（主包 < 2MB）。
- [ ] 分包加载正常（sub/books、sub/orders）。
- [ ] 图片懒加载正常（长列表不卡顿）。
- [ ] 无内存泄漏告警。
