# WeChat Review Checklist

> 微信小程序审核检查清单：提交审核前必须逐项确认，避免审核被拒。

## 小程序基础资料

- [ ] 小程序名称与功能一致（BookNest — 书籍管理与分享）。
- [ ] 头像、简介已配置，与服务类目匹配。
- [ ] 服务类目：「工具 — 办公」或「文化 — 图书」。
- [ ] 隐私协议已配置（页面底部或「我的」页有入口）。
- [ ] 用户协议已配置。
- [ ] 备案信息已提交（如需要）。

## 登录与账号

- [ ] 审核员无需复杂操作即可体验核心功能。
- [ ] 提供审核测试账号或说明：微信登录即可体验。
- [ ] 如果需要 Workspace 权限，提供测试 Workspace 的邀请方式。
- [ ] 不强制收集非必要个人信息（如手机号、身份证）。
- [ ] 登录后明确展示用户身份和权限。

## 支付

- [ ] 支付功能说明清楚：书籍购买、读书会活动报名。
- [ ] 测试环境使用 mock 支付或明确金额极小的测试商品（如 0.01 元）。
- [ ] 支付成功后权益发放逻辑清晰：Ticket 生成 → 查看「我的门票」。
- [ ] 客服入口可用，用户可咨询退款/售后。
- [ ] 退款/售后说明在「我的」页或客服回复中可见。
- [ ] 支付页面不诱导分享、不强制关注。

## 内容安全

- [ ] 用户可发布内容前（书籍、评论）有内容安全检测。
- [ ] 风险内容不会直接展示，而是进入「待审核」状态。
- [ ] 有人工复核或申诉入口（管理员可审核）。
- [ ] 客服入口可用，用户可投诉内容安全误杀。

## 页面内容

- [ ] 无测试文案（如 "test"、"demo"）、无 lorem ipsum。
- [ ] 无调试按钮暴露给普通用户（如 mock 支付按钮在生产环境隐藏）。
- [ ] 无未备案或不可访问外链（所有 URL 为合法域名）。
- [ ] 无诱导分享、诱导关注等风险文案（如 "分享得红包"）。
- [ ] 无赌博、色情、政治敏感内容。

## 技术配置

- [ ] request 合法域名配置完成（含 HTTPS 后端地址）。
- [ ] uploadFile 合法域名配置完成（OSS 上传地址）。
- [ ] downloadFile 合法域名配置完成（OSS 图片地址）。
- [ ] HTTPS 证书有效，不提示不安全。
- [ ] 生产环境关闭 mock callback（`/wechat-pay/mock-callback` 返回 403）。
- [ ] 分包结构正确，主包 < 2MB。
- [ ] 不调用未声明的 API 或权限。

## 审核资料准备

| 资料 | 状态 | 说明 |
|---|---|---|
| 测试账号 | 待准备 | 微信登录即可，无需额外账号 |
| 测试视频 | 可选 | 演示登录、支付、内容安全流程 |
| 功能说明 | 已完成 | 见上方支付、内容安全说明 |
| 隐私协议 | 待准备 | 可在「设置」→「隐私协议」中配置 |
| 用户协议 | 待准备 | 同上 |

## 常见被拒原因 & 对策

| 被拒原因 | 对策 |
|---|---|
| 登录流程不完整 | 确保微信登录后可直接使用核心功能 |
| 支付说明不清 | 明确说明支付用途、金额、售后方式 |
| 内容安全缺失 | 所有 UGC 必须经过后端审核 |
| 类目不匹配 | 确保服务类目与实际功能一致 |
| 外链不可访问 | 所有域名必须合法、已备案、HTTPS |
| 诱导分享 | 检查页面文案，删除诱导性语言 |
