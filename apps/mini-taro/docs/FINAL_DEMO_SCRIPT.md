# Final Demo Script

> 最终演示脚本：BookNest Mini Pro 阶段收官演示路径。

## 演示路径

1. **打开 BookNest Mini 体验版**
   - 微信 → 发现 → 小程序 → 搜索 BookNest（或扫码体验版二维码）。

2. **微信登录**
   - 首页点击「登录」→ 授权微信登录 → 获取 JWT → 进入首页。

3. **查看当前用户和 Workspace**
   - 点击 TabBar「我的」→ 查看头像、昵称、当前 Workspace。

4. **切换 Workspace**
   - 我的页 → 切换 Workspace → 选择另一个 Workspace → 确认切换。

5. **查看书籍列表**
   - 返回首页 → 展示书籍卡片列表 → 封面、标题、作者、价格正常。

6. **搜索书籍**
   - 搜索框输入「Java」→ 过滤结果 → 展示匹配书籍。

7. **创建新书**
   - 点击 TabBar「卖书」→ 填写表单：
     - 书名：「JavaScript 高级程序设计」
     - 作者：「Matt Frisbie」
     - 价格：「99.00」
     - 分类：选择「技术」
   - 保存 → 创建成功。

8. **上传封面**
   - 编辑书籍 → 点击上传封面 → 选择相册图片 → 调用 uploadFile → OSS 返回 URL → 封面展示成功。

9. **保存并进入详情页**
   - 点击书籍卡片 → 进入详情页 → 展示完整信息、封面、评论。

10. **分享详情页**
    - 详情页 → 点击右上角「...」→ 转发 → 分享卡片正常。

11. **编辑书籍**
    - 详情页 → 编辑 → 修改价格 → 保存 → 价格更新。

12. **创建评论并触发内容安全检测**
    - 详情页 → 评论 → 输入「这本书很敏感」→ 提交 → 被拦截 → 提示内容安全审核中。

13. **创建读书会活动**
    - 管理员进入 → 创建活动 → 填写时间、地点、描述 → 保存成功。

14. **创建订单**
    - 选择书籍 → 创建订单 → 展示订单金额。

15. **Mock 支付**
    - 订单页 → 确认支付 → 模拟微信支付 → 支付成功 → 展示支付结果。

16. **支付成功生成 Ticket**
    - 支付成功后 → 自动跳转到订单结果页 → 展示 Ticket 信息 → 状态为 VALID。

17. **订阅活动提醒**
    - 活动详情页 → 点击「订阅提醒」→ 授权订阅消息 → 记录成功。

18. **打开客服入口**
    - 我的页 → 客服按钮 → 打开客服会话 → 发送消息 → 后端接收 CustomerServiceEvent。

19. **管理员进入内容安全复核页**
    - 管理员 → 我的页 → 内容安全 → 展示待审核列表 → 审核通过/拒绝。

20. **查看审计日志**
    - 管理员 → 审计日志 → 展示操作记录（登录、创建、支付、审核）。

21. **展示 CI 上传体验版记录**
    - 打开 GitHub Actions → 展示 `mini-program.yml` 成功运行记录。

22. **展示分包和性能报告**
    - 打开微信开发者工具 → 代码依赖分析 → 展示主包、分包体积 → 打开 `PERFORMANCE_REPORT.md`。
